# Art Gallery

Laura Duran's digital art portfolio showcasing fragments of memory, movement, and home through Caribbean-inspired visual narratives.

## Live Site

Visit the gallery: [https://obito2912.github.io/art-gallery/](https://obito2912.github.io/art-gallery/)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
